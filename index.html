Automatisering & publicering

Denna sida utgör grunden för den första uppgiften i kursen frontend-baserad webbutveckling vid Mittuniversitetet. Uppgiftens syfte är att ge kursdeltagaren färdigheter inom automatisering av utvecklingsmiljö för frontend-baserade webbsidor samt kunskaper om versionshantering och publicering.

För att underlätta arbetsprocessen och automatisera uppgifter ska kursdeltagaren använda sig av utvecklingsverktyget NodeJs. Versionshanteringssystemet Git ska användas för att sköta versionshantering och automatisering vid publicering. Innan publicering ska kursdeltageren även kunna automatisera transpilering och minifiering av CSS, HTML och JavaScript samt automatiskt skapa optimerade grafikfiler.
